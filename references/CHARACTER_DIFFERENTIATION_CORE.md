# CHARACTER_DIFFERENTIATION_CORE

> Character Differentiation sub-layer.
> Purpose: make multiple characters visually and behaviorally distinct without relying on hair-color swaps.

## 1. Differentiation matrix

For each important character, define a readable combination across:

### Face
- base eye family
- gaze quality
- eyebrow behavior
- mouth/expression amplitude
- head-angle tendency

### Hair
- silhouette
- length / mass
- parting / framing
- texture
- tied structure
- accessory anchor
- motion response

### Body
- height/frame
- stance
- movement amplitude
- occupied space
- center-of-gravity tendency

### Wardrobe
- faction/role continuity
- neatness / looseness
- formality
- layering
- accessory discipline
- shoes/bag/personal objects

### Color
- dominant mass
- support colors
- accent
- neutral grounding

### Behavior
- gesture amplitude
- hand tension
- personal distance
- prop handling
- reaction latency
- approach / retreat tendency

## 2. The five-channel rule

A new character should not depend on one distinctive feature.
Prefer at least several independent channels:
`head silhouette + face behavior + wardrobe behavior + gesture + prop/social behavior`.

## 3. Same-uniform test

If characters share a uniform:
1. preserve faction identity
2. vary wear attitude
3. vary hair/head silhouette
4. vary posture/gesture
5. vary role props
6. vary expression amplitude

If only hair color changes, redesign.

## 4. Same-emotion test

Give two characters the same emotion.
They should differ in:
- amplitude
- gaze
- mouth/eyebrow balance
- shoulder/body propagation
- self-touch
- movement

Emotion must not erase identity.

## 5. Same-action test

Give two characters the same action:
`wave / point / sit / run / hold a bag / read / greet`.
If their pose becomes interchangeable, the personality-to-body mapping is too weak.

## 6. Ensemble design

Before group posing, build a compact relationship graph:
- leader / follower
- challenger / challenged
- protector / protected
- close / distant
- admires / resents
- initiates / reacts

Then translate relationships into:
- spacing
- orientation
- touch
- gaze
- height/level
- movement order
- overlap

## 7. Color hierarchy

Use palette roles, not rigid hue stereotypes:
- dominant
- support
- accent
- neutral

Project palette / faction palette / lighting conditions outrank generic character-color recipes.

## 8. Anthropomorphism adapter

Motif -> extract:
`shape / color / texture / function / motion / association`
-> choose 2–4 strongest cues
-> map to:
`silhouette / hair / costume / prop / gesture`
-> verify character still reads as a person, not a walking icon pile.
