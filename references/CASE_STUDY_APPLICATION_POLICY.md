# Case Study Application Policy

## Loading order
1. User-provided image/style/reference
2. Named character/student reference folder
3. School/faction case DNA
4. Task-specific scene / UI / PV case references
5. Neutral theory core
6. Default Blue Archive case anchor only when no stronger style reference exists

## Do not
- turn one franchise observation into a universal art law
- replace character identity with school-average traits
- use raw case images as a reason to ignore camera/light/story requirements
- mix unrelated case pages into prompts without a task reason

## Derivative work
For a named student, identity locks outrank aesthetic novelty. Change scene/camera/light freely; change face/hair/halo/signature motif only when the user explicitly asks for redesign.
