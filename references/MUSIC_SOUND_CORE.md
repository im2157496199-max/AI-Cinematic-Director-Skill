# MUSIC_SOUND_CORE.md

> Unified music-design layer for anime/game/AI-video workflows.
> Goal: use music as narrative, emotional, identity, temporal, and worldbuilding structure.
> Not a conservatory-composition course and not a fixed "anime sound" generator.

## Pipeline

STORY / CHARACTER / SETTING
→ EMOTIONAL & NARRATIVE MAP
→ EDITING EVENT MAP
→ MUSIC FUNCTION
→ CUE / MOTIF / STATE DESIGN
→ RHYTHM / HARMONY / TIMBRE / INSTRUMENTATION
→ LAYER / TRANSITION DESIGN
→ MUSIC GENERATION OR SELECTION
→ AUDIO-VISUAL REVIEW
→ CASE LIBRARY UPDATE

## 1. Music function first

For every cue, define:
- narrative_function
- target_emotion
- character/location association
- audience knowledge
- energy trajectory
- diegetic status
- dialogue/sfx competition
- entry reason
- exit reason

Do not begin from vague genre tags such as `epic anime music`.

## 2. Narrative device

Music may:
- establish identity
- foreshadow
- recall memory
- mark growth/change
- create contrast/irony
- reveal hidden emotional meaning
- define location/faction/culture
- signal danger/reward/progress
- bridge scenes
- withhold itself for silence

## 3. Motif system

For important entities/events:
- motif_id
- associated_entity
- recognizable core
- transformations
- current meaning

Transform motif via:
tempo / mode / harmony / register / rhythm / orchestration / density / timbre / fragmentation.

Reuse should communicate changed meaning, not just repeat the same file.

## 4. Short-form identity / OP logic

For opening/title/teaser music, optionally compress:
attention hook -> setup -> buildup -> climax -> exit/tag.

A bright/striking `call` can create instant identity, but is OPTIONAL.
Do not force Royal Road progressions, J-pop harmony, or bright timbre on every anime project.

## 5. Musical states

Linear video may still benefit from state logic:
- ambient
- neutral
- curiosity
- tension
- danger
- action
- aftermath
- intimacy
- revelation
- grief
- triumph
- custom project states

States are project-specific.

## 6. Horizontal and vertical change

Horizontal:
switch/resequence cue sections when the narrative state changes substantially.

Vertical:
add/remove functional stems while keeping one coherent musical identity.

Prefer hybrid use:
small intensity change -> vertical
major narrative/world/state change -> horizontal
but allow exceptions.

## 7. Transition design

Every important transition chooses one:
- hard cut
- musical cadence
- overlap
- crossfade
- bridge
- riser
- stinger
- drop to silence
- motif handoff
- pre-lap / anticipatory change

Do not let music merely chase every edit one frame late.

## 8. Audio-visual alignment has separate dimensions

Evaluate separately:
- semantic fit
- emotional fit
- narrative fit
- temporal boundary fit
- rhythmic/beat fit
- dialogue/SFX fit
- continuity across shots

"Matches the video" is too vague.

## 9. Music and sound design relationship

Choose:
- separated
- mixed
- unified

If unified, environmental/action sounds may share scale, rhythm, timbre, or motif with music.

## 10. Cultural and stylistic codes

Treat genre/instrument/harmony/timbre associations as context-sensitive.
Ask:
- whose musical code?
- for which audience?
- is it story-grounded?
- is it stereotype or actual project language?

Do not universalize "major=happy", "traditional instrument=Japan", etc.

## 11. Lyrics / vocals

When lyrics are present, analyze:
- narrative point of view
- character alignment
- explicit vs subtext meaning
- cultural/rhetorical coding
- whether vocals compete with dialogue
- whether lyric content changes scene interpretation

## 12. AI generation spec

Before calling a music model, compile:
- duration
- scene structure
- target emotion trajectory
- tempo band
- rhythmic density
- key/mode only if actually needed
- motif requirements
- instrumentation/timbre
- energy curve
- transition points
- accent/stinger points
- silence windows
- dialogue windows
- forbidden clichés
- reference case cards

## 13. OST / real-audio analysis

When the user supplies music, analyze it as a case:
- function
- structure
- tempo/rhythm
- harmony
- motif/theme
- timbre/instrumentation
- energy curve
- identity cues
- entry/exit logic
- relationship to scene/cuts/dialogue
- transferable patterns
- project-specific non-transferable traits

If corresponding video is available, perform joint audio-visual analysis.

## 14. Ownership

Theory defines coherence.
Case library defines taste.
Current project references define the actual target.

No theory source may silently force a fixed franchise/style.
