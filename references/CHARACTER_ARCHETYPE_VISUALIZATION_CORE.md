# Character Archetype Visualization Core

Purpose:
Bridge archetype/personality concepts into visible, image-executable character decisions.

## Runtime route
`role -> archetype hypothesis -> motive/energy -> visible behavior -> shape/proportion -> face -> costume attitude -> prop -> color hierarchy -> prompt`

## Active rules

1. Archetype is upstream, not decorative.
   - Use it to decide how the character occupies space, not only what keywords to add.

2. Translate label into motive/energy first.
   - Example: `leader` -> stable, self-possessed, space-controlling.
   - Example: `caregiver` -> attentive, receptive, support-oriented.

3. Choose a dominant shape family.
   - rounded / angular / square / mixed.
   - Dominant family should support the intended read, not erase variety.

4. Use proportion intentionally.
   - head/body ratio, shoulder width, limb emphasis and mass distribution change impression.

5. Protect base identity under emotion changes.
   - eye construction, brow family, facial mass and silhouette should persist.

6. Pose completes the archetype.
   - A calm archetype should show calm through stance and gesture, not only expression text.

7. Props are optional but meaningful.
   - Add a prop when it clarifies role/habit/status.

8. One archetype can produce multiple surface looks.
   - Keep the invariant meaning; vary costume, age, world and palette.

9. Contrast is allowed.
   - Contradiction is often the point: cute face + controlled distance; sharp uniform + soft empathy.

10. Compile visible consequences, not labels.
   - Prefer `upright posture, measured gesture, contained expression, squared silhouette accents`
   - over `leader archetype` alone.

## AI generation handoff
Required fields before prompting:
- role
- primary trait / archetype
- secondary trait or contradiction
- space behavior
- face behavior
- silhouette / shape tendency
- color hierarchy
- costume attitude
