## Runtime extraction

1. Character is not a trait checklist; build through want, obstruction, adjustment and choice.
2. Use the five cornerstones as diagnostics, not a mandatory formula.
3. Give characters a concrete dramatic desire while allowing deeper or conflicting wants below it.
4. Frustrated desire creates adaptations / defenses; these make behavior individual.
5. Contradiction should emerge from the person, not random “quirky” stacking.
6. Vulnerability and wounds matter only when they affect present behavior.
7. Secrets create a gap between visible behavior and hidden intent.
8. Build biography from consequential scenes/events rather than exhaustive data fields.
9. Physical, psychological and sociological detail is useful when it affects action, voice, relation or visual identity.
10. Quirks, tics and habits are high-salience identifiers but should be sparse.
11. Different relationships can reveal different versions of the same character.
12. In scenes, objective + obstacle + adjustment is a practical behavioral test.
13. Dialogue should pursue an objective; it is action, not information dumping.
14. Character voice is driven by attitude, desire, fear, background and relationship—not only catchphrases.
15. In multi-character scenes, distinct objectives help create distinct voices.

## AI adaptation notes

- Store character psychology in a Character Bible, not in the final image prompt.
- Compile only visible consequences: posture, choice, distance, gaze, task, wording, reaction, costume handling, prop use.
- Do not inherit any default visual style from the book’s examples.
