# 07_directing_actors_skill_extraction.md

Source: Judith Weston — *Directing Actors: Creating Memorable Performances for Film and Television*  
Purpose: performance-direction extraction.  
Note: This is a user/project-created extraction, not a replacement for the copyrighted book.

## High-value runtime concepts

- Result Direction vs Playable Direction
- Verbs
- Facts
- Images
- Events
- Physical Tasks
- Objective
- Action Verbs
- Spine / through-line
- Moment-by-moment
- Listening
- Subtext
- Physical Life
- Props and costume as behavior
- Transitions
- Blocking / stage business

## AI translation

The key conversion is:

```text
emotion label
-> objective
-> action verb
-> physical task / prop interaction
-> body / gaze / distance / contact
-> visible prompt claims
```

Avoid treating the book as an emotion-pose dictionary.

## What stays reference-only

- casting workflow
- on-set interpersonal etiquette
- actor career / rehearsal management detail
- child / non-actor specifics unless a task actually needs them
