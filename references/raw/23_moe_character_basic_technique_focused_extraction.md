# 萌えキャラクターの描き分け 基本テクニック編 — Focused / Deduplicated Extraction

> Project role: systematic character differentiation across face, hair, expression, wardrobe, gesture, group relation, and optional anthropomorphism.
> Status: Character Embodiment source 3/4.
> Source is a scanned Japanese art book; copyrighted pages are not redistributed.
> This file contains paraphrased project rules only.

## SOURCE ROLE

This book is especially useful because it treats "character differentiation" as a system:
same general moe/anime base -> differentiate through eye family, hair, expression, outfit coordination, gesture/pose,
and relationship to other characters.

The transferable value is NOT its period-specific moe style.
The transferable value is the idea that personality must remain readable through multiple visual channels.

## ACTIVE RULES

### CD01 — Personality is the differentiating cause, not a decorative label
Do not create five characters by changing only hair color.
Differentiate through a coherent bundle:
`face -> eye family -> hair silhouette -> expression amplitude -> clothing attitude -> gesture -> interaction`.

### CD02 — Use high-signal facial variables independently
Separate:
- base eye family / eyelid angle
- eye openness
- eyebrow shape/tension
- mouth amplitude
- head angle
- gaze quality

A "character type" should not be encoded by one single feature.

### CD03 — Eye family is a prior, not destiny
Upturned / droopy / sleepy / flat / neutral eye families can change first impression,
but they MUST NOT hard-code personality.
Context, behavior, relationship, and project reference can override the stereotype.

### CD04 — Preserve facial identity across emotion
Same emotion should look different on different base faces.
Do not replace the character's original eye construction merely to express anger, joy, embarrassment, or surprise.

### CD05 — Hair is silhouette + rhythm + behavior
Differentiate hair by:
- length
- mass
- parting
- side framing
- curl/wave/straightness
- ponytail/twin-tail/braid/bun structure
- accessory placement
- motion response

Hair should support personality/role without becoming a deterministic personality code.

### CD06 — Wardrobe is a behavior channel
Clothing communicates:
- role/faction
- neatness vs looseness
- formality
- comfort vs display
- activity readiness
- social confidence
- personal taste

For shared uniforms, vary how the uniform is worn before replacing the uniform itself.

### CD07 — Outfit coordination needs one hierarchy
Do not assign equal visual weight to hair, eyes, skin, top, skirt, socks, shoes, and accessories.
Choose:
- dominant color / mass
- supporting color(s)
- accent
- neutral / grounding tones

Exact printed color formulas are reference-only; relational hierarchy is the transferable rule.

### CD08 — Body type is a design variable, not a personality verdict
Height, frame, bust, limb length, and body volume can differentiate characters,
but must follow age/context/role and must not be assigned as fixed personality stereotypes.

### CD09 — Same gesture must remain character-specific
A wave, point, fist, book-hold, bag-hold, sit, walk, run, or fall should differ by:
- hand tension
- elbow path
- shoulder openness
- torso participation
- stance
- gaze
- expression amplitude
- personal space

This MERGES with the gesture/action rules from source 2/4.

### CD10 — Small props are part of character readability
Bags, phones, books, hats, hair accessories, jewelry, shoes, and personal objects can carry identity.
Use a prop only when it has role/behavior meaning; avoid random accessory clutter.

### CD11 — Group design needs contrast axes
For 2+ characters, deliberately choose contrast on several axes:
- personality energy
- eye/hair silhouette
- height/body proportion
- outfit wearing style
- gesture amplitude
- color mass
- social role
- relationship stance

The goal is ensemble readability, not forced opposition on every axis.

### CD12 — Relationship changes visual behavior
Character difference is clearer when characters interact.
Track:
- who approaches / retreats
- who occupies more space
- who touches whom
- who looks first
- who interrupts / waits
- who leads movement
- who mirrors whom

This connects character differentiation to staging and directing.

### CD13 — Character pair / trio / ensemble should have relational geometry
For pairs/trios/groups, define a relationship graph before final pose design.
Avoid "four unrelated solo characters standing side by side".

### CD14 — Situation is part of characterization
Designing characters in a specific situation (leaving school, sleepover, club activity, shopping, etc.)
reveals differences that a neutral lineup hides.
Use situation as a test bench for personality.

### CD15 — Original-character process: trait -> relation -> situation
Useful lightweight order:
1. decide each character's core difference
2. define relationship among them
3. place them in a situation
4. verify that faces, clothes, gestures, and spacing still read differently

### CD16 — Anthropomorphism should decompose the motif
For object/food/animal anthropomorphism, do not just put a motif icon on clothing.
Extract:
- dominant shape
- color relationship
- texture/material
- function/use
- motion/behavior
- emotional association
Then map only the useful subset into face/hair/outfit/prop/pose.

## MERGE WITH EXISTING SKILL

- Source 1/4: personality -> visible behavior.
- Source 2/4: physical action chain, support/contact, full-body propagation.
- Costume Core: purpose/material/function/world consistency outranks decorative outfit matching.

- Color/Light: printed palette examples do not override scene lighting or project color script.

## REFERENCE_ONLY

- exact CMYK values and print-oriented color recipes
- fixed 2010s/2014 moe-fashion examples
- exact "cute face" geometric proportions as a universal rule
- fixed 6-head-body default
- specific Gothic Lolita / office / casual clothing catalog details
- deterministic mappings such as eye type = personality
- exact body/bust/height stereotypes

## STYLE FIREWALL

DO NOT:
- force the book's moe face as default
- use eye shape as a personality diagnosis
- assign hair length, body type, bust size, or skirt length from personality alone
- hard-code "tsundere -> upturned eyes", "gentle -> droopy eyes", etc.
- replace Blue Archive / project case-library design language with this book's period styling

Use the book as a differentiation engine, not a style destination.
