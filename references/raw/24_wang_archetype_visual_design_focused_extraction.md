# Angela Wang — An Approach to Design Visuals for Archetypes Based on Character Archetype Taxonomies — Focused Extraction

> Project role: convert archetype labels into usable visual design decisions without reducing characters to clichés.
> Status: Character Embodiment source extension.
> This file contains paraphrased project rules only.

## SOURCE ROLE

This thesis is useful because it does not treat archetypes as mere writing labels. It proposes a formal path from:
- archetype / personality concept
- to visual semiotics
- to proportion / shape / face / pose / props
- to a readable final design.

The transferable value is NOT a single fixed art style.
The transferable value is the idea that visual decisions should have semantic reasons.

## ACTIVE RULES

### AV01 — Archetype is a design hypothesis, not a costume preset
An archetype is a starting assumption about values, drives, or social energy.
It must be translated into visual logic before it affects face, outfit, or pose.
Do not generate `hero / villain / tsundere / caretaker` as raw labels only.

### AV02 — Start from generic likeness before stylization
The thesis method begins by describing a model with a compelling real-world reference,
then testing which proportional changes preserve identity while shifting impression.
For runtime use:
- define the base human read first
- then stylize proportion, silhouette and emphasis
- do not stylize before deciding what the audience must read.

### AV03 — Use visual semiotics, not arbitrary decoration
Every major design choice should answer at least one of:
- what role/social function is signaled?
- what emotional tendency is signaled?
- what power / fragility / warmth / distance is signaled?
- what part of the archetype is being emphasized or omitted?

### AV04 — Proportion changes shift psychology read
Relative proportion is not neutral.
Useful axes:
- head-to-body ratio
- shoulder width vs hip width
- limb length
- torso compactness
- eye/head emphasis
- hand/foot size emphasis
Use proportion to shift impression, not only age.

### AV05 — Shape language carries attitude
Map archetype energy into dominant shape tendencies:
- rounded / soft -> warmth, openness, harmlessness, softness
- angular / sharp -> tension, resolve, precision, danger, severity
- squared / blocky -> stability, rigidity, mass, duty
Do not use one shape family exclusively; choose a dominant and supporting set.

### AV06 — Face design is a controlled priority stack
The most portable face controls are:
- eye family
- eyelid weight
- eyebrow angle
- cheek/face fullness
- nose/mouth simplification
- forehead/chin proportion
Do not let expression-only changes overwrite base identity.

### AV07 — Pose and staging complete the archetype read
An archetype is not fully readable in a neutral T-pose.
Pose must show:
- how the character occupies space
- whether they advance / guard / retreat / contain / entice / support
- whether energy flows outward or inward
Use stance and staging before adding decorative props.

### AV08 — Props and omission are both semantically active
Adding props can clarify role and activity.
Omitting props can create simplicity, purity, abstraction, mystery, or severity.
Do not add props merely to fill space.
Use props when they materially strengthen role, habit, or narrative function.

### AV09 — Appeal is not decoration layered after meaning
The thesis explicitly keeps aesthetic appeal in the loop.
For runtime this means:
- semantic clarity must coexist with pleasing rhythm / silhouette / focal hierarchy
- a correct design that is visually dead is incomplete
- an attractive design with no readable logic is unstable.

### AV10 — One archetype can yield multiple valid looks
Do not hard-code one visual formula per archetype.
Instead define:
- invariant core meaning
- variable surface expression
Example:
`leader` might read through composure and space control,
while silhouette, age, costume and palette can still vary across settings.

### AV11 — Contrast is often clearer than direct labeling
A reserved or conflicted archetype may read best through contrast:
- soft body language + sharp gaze
- formal clothing + relaxed pose
- cute face + controlled distance
Use contradiction intentionally when it is the design point.

### AV12 — Build a reusable translation chain
Recommended runtime route:
`archetype -> motive/energy -> shape/proportion -> face -> posture -> prop -> costume attitude -> color hierarchy`.
Do not jump directly from archetype to prompt keywords.

### AV13 — Use real-world referents as anchor, not prison
Real-world reference helps stabilize proportion, function and recognizability.
But the output does not need to stay realistic.
Reference clarifies the design problem; stylization solves the project goal.

### AV14 — Role meaning outranks fashionable surface tropes
A fashionable archetype look can be useful, but a readable role is more important.
If style trends and role meaning conflict, keep the role read.

### AV15 — Archetype routing belongs upstream of costume and prompt compilation
Archetype should influence later layers:
- gesture
- costume attitude
- color emphasis
- camera treatment
not remain isolated as a writing note.

## MERGE WITH EXISTING SKILL

- Character Embodiment: archetype becomes an upstream driver for visible behavior.
- Character Differentiation: archetype helps separate ensemble members beyond color and hair.
- Costume Core: role/function/world constraints still outrank free archetype styling.
- Directing/Staging: pose and spatial authority finalize the archetype read.
- Prompt Compiler: archetype itself is often too abstract; compile its visible consequences.

## REFERENCE_ONLY

- exact thesis showcase designs as mandatory style targets
- any single encyclopedic archetype sheet as universal solution
- defaulting all heroes to large eyes and all villains to sharp shapes
- treating proportion changes as deterministic personality diagnosis

## STYLE FIREWALL

DO NOT:
- convert archetypes into one-line visual clichés
- use semiotics as a justification for clutter
- let appeal erase clarity or clarity erase appeal
- treat the thesis' presentation style as the project's only valid aesthetic
