## Runtime translation

Primary use is not “add more camera jargon.”
Primary use is to force this ordering:

```text
understand scene
-> identify event and audience alignment
-> design staging
-> choose camera narration
-> design shots
```

## What stays reference-only

- production management details
- producer / crew responsibility
- historical case-study detail when it does not produce a reusable directing decision
- book-specific screenplay text

Case studies may remain useful for audit but should not be copied wholesale into runtime rules.
