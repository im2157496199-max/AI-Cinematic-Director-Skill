# Expression and Gesture Application

Goal:
Improve character acting.

Rules:
- Same emotion can appear differently depending on personality.
- Face alone is insufficient; combine:
  eyes + mouth + hands + shoulders + posture.

Examples:
Happy:
- energetic character: larger movement
- calm character: smaller expression

Scene interaction:
Characters should face each other and react naturally.
Avoid identical front-facing expressions.

AI prompt conversion:
Emotion -> facial features -> gesture -> pose -> camera relation
