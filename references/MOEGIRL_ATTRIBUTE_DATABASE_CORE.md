# MOEGIRL CHARACTER ATTRIBUTE DATABASE CORE

## Source
Moegirl dataset (moegirl-dataset-main).

## Purpose
Use the dataset as a character attribute reference layer, not as a replacement for character design theory.

The dataset provides structured information such as:
- character attributes
- character relationships
- work information
- tags / moe attributes
- hair color attributes
- eye color attributes
- character metadata

## Important rule
Attributes are evidence, not a complete character.

Do not generate:
"tsundere + red eyes + black hair = character"

Instead:

```
attribute
 -> personality possibility
 -> visual confirmation
 -> behavior confirmation
 -> final character design
```

## Runtime uses

### 1. Character attribute lookup
Useful for:
- discovering recurring traits
- finding similar character patterns
- building reference groups

### 2. Attribute clustering
Combine:
- appearance
- personality
- role
- costume
- behavior

Avoid single-tag matching.

### 3. Character differentiation
For a cast:
check differences in:
- silhouette
- hair
- eyes
- palette
- personality
- relationship role

Do not separate characters only by moe attributes.

### 4. Reference retrieval
When creating a new character:
retrieve:
- similar archetype
- similar visual combination
- similar role pattern

Then deliberately modify.

## Data limitations

The database describes existing characters.
It does not directly provide:
- good design rules
- artistic quality
- narrative depth
- scene composition

Use with:
- Character Embodiment Core
- Archetype Visualization Core
- Costume Design Core
- Manga Sequential Core

## AI generation rule
Database tags must be converted into visible instructions.

Example:

Input:
"quiet caretaker"

Do not output only:
"kind girl"

Convert:
- softer expression
- open body language
- supportive gesture
- warm palette
- practical costume details
