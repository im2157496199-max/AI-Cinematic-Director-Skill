# SPACE_DESIGN_CORE.md

> Shared environment topology layer. Owns space organization, not architectural engineering and not final art style.

## Pipeline position

STORY / USER INTENT
→ ART DIRECTION / PRODUCTION DESIGN
→ SPACE DESIGN
  - topology / organization
  - enclosure / openings
  - circulation / reveal sequence
  - scale / human anchors
  - environmental hierarchy / rhythm
→ LIGHT_COLOR
→ DIRECTOR / CINEMATOGRAPHY
→ MODEL ADAPTER

## Spatial intent
Choose what the space should make the viewer/character feel spatially:
intimate / protected / exposed / monumental / oppressive / open / labyrinthine / ceremonial / domestic / efficient / playful.

Then implement with actual spatial choices, not adjectives alone.

## Topology
Primary organization when useful:
centralized / linear / radial / clustered / grid / hybrid

Relationships:
within / interlocking / adjacent / linked_by_common_space

## Enclosure
Represent boundary strength and openings separately.

## Circulation
Treat movement as:
approach -> threshold -> path -> node -> destination -> exit/continuation

Main route must remain distinguishable from secondary paths.

## Reveal control
Useful transitions:
compress/release
obscure/reveal
low/high
narrow/broad
ordinary/dominant
dark/light (handoff to LIGHT_COLOR)

## Scale
Define:
- scale_mode: intimate | human | monumental | mixed
- familiar anchors
- distance/depth layers

For megastructure shots, include at least one readable human/familiar anchor unless deliberate abstraction is requested.

## Spatial hierarchy
Rank important environment elements through:
- size exception
- shape exception
- placement exception

Never make all elements exceptional.

## Rhythm
Define a repeated family and cadence:
regular / irregular / gradual / interrupted

Allow one controlled break for emphasis.

## Handoff
- SPACE_DESIGN tells Cinematography what spatial opportunities exist.
- Cinematography decides how the camera frames them.
- SPACE_DESIGN tells LIGHT_COLOR where openings/volumes/material classes are.
- LIGHT_COLOR decides how light/material response appears.
- Art Direction decides style, palette intent, material language, era, and taste.
