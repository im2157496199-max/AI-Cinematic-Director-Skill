# T02_ecology_environment_prompt.md

## 目标
生成具备生态关系、行动路径、战斗可读性、情绪氛围的环境设计方案。

## Prompt 骨架
### 1. 区域定义
- 大地貌：古森林 / 峡谷 / 洞窟 / 火山 / 珊瑚高地 / 沼地 / 遗迹
- 主色系统
- 光线系统
- 栖息生物类型

### 2. 生态规则
- 谁在这里生存
- 谁捕食谁
- 巢穴在哪里
- 危险地形是什么
- 玩家/角色如何移动

### 3. 视觉要求
- 远景要有主地标
- 中景要有战斗空间
- 近景要有材料细节
- 色彩必须服务生态和情绪

## 结果格式
- 地区名
- 生态主题
- 区域分层
- 生物关系
- 关键视觉点
- AI 生成提示词
