# T01_creature_concept_prompt.md

## 目标
生成“像真正存在于生态系统中的怪物/魔物”设计方案。

## Prompt 骨架
### 1. 生物定位
- 类别：飞龙 / 牙兽 / 两栖 / 甲壳 / 古龙感 / 混合型
- 生态位：顶级掠食者 / 伏击者 / scavenger / 群居 / 防御型
- 栖息地：森林 / 沼泽 / 火山 / 冰原 / 珊瑚 / 瘴气 / 结晶地貌

### 2. 身体逻辑
- 主要移动方式
- 主要攻击方式
- 主要感官器官
- 防御结构
- 展示/威吓结构

### 3. 视觉输出要求
- 轮廓必须一眼识别
- 器官必须服务攻击方式
- 皮肤/甲壳/羽毛/骨质要能说明环境适应
- 不要无意义装饰

## 结果格式
- 怪物名
- 生态描述
- 身体结构说明
- 攻击方式说明
- 弱点与风险
- 视觉关键词
- AI 生成提示词
