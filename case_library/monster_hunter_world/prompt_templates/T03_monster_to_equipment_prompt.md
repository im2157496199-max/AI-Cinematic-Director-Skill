# T03_monster_to_equipment_prompt.md

## 目标
把怪物素材转译成武器/盔甲，而不是做无来源的奇幻装备。

## Prompt 骨架
### 1. 来源怪物
- 怪物类型
- 材料关键词：甲壳 / 羽毛 / 骨 / 毒囊 / 角 / 鳞片 / 结晶 / 火焰器官
- 情绪：凶暴 / 优雅 / 腐败 / 神圣 / 寒冷 / 迅捷

### 2. 装备目标
- 武器类型
- 护甲定位
- 使用者身份
- 稀有度 / Prestige 等级

### 3. 转译规则
- 装备外观必须看出怪物来源
- 材料纹理必须有继承关系
- 轮廓要区分职业
- 功能件有位置逻辑

## 输出格式
- 装备名
- 来源说明
- 设计逻辑
- 视觉重点
- AI 生成提示词
