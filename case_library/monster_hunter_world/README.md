# Monster Hunter: World Integration

定位：
不是普通作品补充包，而是 **Creature / Ecology / Equipment** 能力层。

## 为什么要进入主 Skill
《怪物猎人世界》的高价值不在“剧情百科”，而在以下四种设计能力：
1. **怪物设计**：身体结构、栖息逻辑、攻击器官、轮廓差异
2. **生态环境**：区域气候、地貌、植被、环境与生物关系
3. **装备转译**：怪物素材如何转成武器、防具、猎人职业视觉
4. **功能型幻想设计**：一切设计都尽量保持“像真的能活 / 能用 / 能运作”

## 本轮处理原则
- 逐页建立 inventory
- 只吸收高价值样本，不做笨重图库
- 把作品学习转成可复用规则，而不是只收图
