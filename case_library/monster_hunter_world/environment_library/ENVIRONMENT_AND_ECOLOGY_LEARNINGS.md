# Environment & Ecology Learnings — Monster Hunter: World

## 核心规则
1. **环境是行为舞台，不只是背景。**
   好的场景要能解释：猎物怎样藏、怪物怎样伏击、玩家怎样观察与移动。

2. **每个区域要有主导生态信号。**
   - 古代森林：层级、潮湿、绿色密度、垂直穿梭
   - 陆珊瑚台地：轻盈、珊瑚状材质、梦幻空气感
   - 瘴气之谷：衰败、毒性、尸骸、低能见度
   - 龙结晶之地：热、矿物、晶体、火与反光

3. **可读性优先于纯写实。**
   怪猎的环境虽然复杂，但路径、战斗区、危险区、观景区往往能被快速区分。

4. **色彩不只是好看，而是生态提示。**
   蓝紫 / 荧光 → 神秘、异质、腐败、能量
   黄橙 / 熔岩 → 热、危险、活动强烈
   绿色高饱和 → 生长、潮湿、生命密度

5. **局部材料要为生物服务。**
   藤蔓、泥、骨、鳞片、晶体、腐殖质等材料，与生物行为和巢穴逻辑紧密相关。

## 对 Skill 的作用
- 场景设计时，不再只写“森林/洞穴/火山”。
- 要求输出：地貌逻辑 + 生物关系 + 光线 + 行动路径 + 情绪。
