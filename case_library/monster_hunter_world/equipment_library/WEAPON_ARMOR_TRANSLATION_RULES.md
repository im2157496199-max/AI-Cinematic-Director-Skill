# Equipment Translation Rules — Monster Hunter: World

## 核心规则
1. **装备应该看得出来源。**
   优秀装备不是“另起炉灶”，而是把怪物的：
   - 甲壳
   - 角 / 爪 / 齿
   - 羽 / 翼膜
   - 颜色 / 花纹
   转译成可穿戴、可挥舞、可识别的装备语言。

2. **职业轮廓必须清晰。**
   巨剑、太刀、弓、长枪、轻重弩等都要在 silhouette 上一眼区分。

3. **同素材装备既统一又分化。**
   同一怪物素材做出的装备，应共享：
   - 材质
   - 花纹
   - 配色
   但根据武器种类与性别/职业需求做轮廓差异。

4. **功能件不能乱画。**
   绑带、护甲片、背包、药瓶、挂件都应说明“为什么在这里”。

5. **Prestige design（高阶感）来自秩序与稀有材料，而不是无脑堆满。**

## 用法
- 角色装备设计：先选来源生物，再选武器类型，再选猎人职业定位。
- 盔甲设计：优先从材料逻辑出发，而不是先堆装饰。
