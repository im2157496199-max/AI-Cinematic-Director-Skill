# Creature DNA Learnings — Monster Hunter: World

## 核心规则
1. **怪物先是生物，再是怪物。**
   设计时先问：它如何移动、捕食、防御、展示、栖息？再问视觉是否够酷。

2. **攻击方式必须写进身体结构。**
   - 吐息系：喉部 / 胸腔 / 口腔器官需要支持
   - 冲撞系：头骨、肩部、角、前肢要有支撑
   - 飞行系：翼膜、胸肌、尾部平衡需要可信

3. **轮廓要一眼识别生态角色。**
   例如：
   - 肥大腹部 / 张开结构 → 膨胀、储气、喷吐
   - 高背棘、外翻甲片 → 防御 / 威吓 / 族群辨识
   - 细长四肢与低身位 → 速度与伏击

4. **变种不是换色，而是换重点。**
   亚种 / 特殊个体应在：
   - 器官
   - 材质
   - 行为提示
   - 危险等级
   上做增强，而不是只换颜色。

5. **怪物与环境必须互相证明。**
   看到环境，就能猜它适合什么生物；看到生物，也能反推出它来自什么环境。

## 对 Prompt / Skill 的具体用法
- 当用户要原创怪物时：
  先定义生态位 → 定义攻击器官 → 定义运动方式 → 定义轮廓 → 再上装饰。
- 当用户要“像怪猎”的怪物时：
  优先参考本库 selected 中的 monster hero pages，再叠加 habitat 规则。
