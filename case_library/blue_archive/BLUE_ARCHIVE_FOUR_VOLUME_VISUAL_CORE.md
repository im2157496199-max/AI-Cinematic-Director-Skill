# Blue Archive Four-Volume Visual Core

Purpose: consolidate the art-book case study into a reusable visual decision layer for character design, secondary creation, scene design, CG/PV planning and UI/graphic reference.

This is a **case library**, not the neutral theory core. When a user supplies another style/reference, that reference wins.

## 1. Character identity hierarchy
For a named student, load in this order:
`student profile -> school/faction DNA -> variant/concept references -> scene/cut references -> neutral theory rules`.

Identity is usually carried by a small invariant set:
- face family / eye construction
- hair silhouette and major color mass
- halo / faction emblem
- one signature prop/weapon family
- one dominant costume/shape anchor

Alternate outfits should change **silhouette, material, behavior and context together**. Do not make variants by recoloring the base costume.

## 2. School / faction grammar
A school is a prior, not a prison. Shared palette, uniform construction, motifs and prop language create belonging; the student's own silhouette and personality override averages when they conflict.

## 3. Character readability
Commercial anime characters remain readable because multiple channels agree:
`silhouette + hair + face + color hierarchy + costume attitude + prop + gesture`.
Hair color alone is never enough.

## 4. Memorial Lobby / intimate portrait grammar
The strongest scenes are environmental portraits, not character-on-background composites.
Every scene should answer:
- what is the student doing?
- what supports or constrains the body?
- what object proves this is their moment?
- where is the primary light?
- what part of the frame is intentionally quiet?

## 5. Environment grammar
Kivotos feels lived-in through functional detail: transit, signs, fences, stairs, club rooms, labs, streets, shrines, school furniture and district-specific motifs. Functional geography beats generic decorative density.

## 6. Light / color grammar
The case library repeatedly separates narrative states by color script:
- high-key cyan/white: everyday school life, openness, summer
- low-key blue/violet: solitude, threat, control, night
- magenta/red: crisis, impact, unstable energy
- amber/gold: intimacy, memory, release, emotional closure

These are observed tendencies, not a universal symbolism table.

## 7. PV / story-cut grammar
Do not generate independent pretty frames. Sequence logic should preserve:
- geography
- screen direction / action direction
- color state
- emotional escalation
- focal hierarchy

Wide/establishing information often precedes close emotional shots. VFX should preserve sides, silhouette and direction rather than fill the frame uniformly.

## 8. Rough-to-final lesson
Rough and animation pages show that the durable information is:
`crop -> silhouette -> action line -> value mass -> light direction -> color state`.
Fine texture and accessories arrive later. AI iteration should protect those upstream decisions.

## 9. UI / graphic lesson
Blue Archive's graphic system is restrained: strong flat accent, bold sans typography, precise spacing, thin rules and large white fields. Use the hierarchy logic; do not blindly copy typography.

## 10. Runtime rule
If the user does not specify a style and asks for an anime/commercial-character visual, this project may use Blue Archive as the default high-priority case anchor. If the user specifies another style, artist, work or reference image, disable this default unless explicitly asked to mix them.
