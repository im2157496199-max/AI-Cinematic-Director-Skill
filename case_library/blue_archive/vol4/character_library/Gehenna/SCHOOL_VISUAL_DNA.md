# Gehenna — Volume 4 school visual DNA

## Observed grammar
Strong black/red contrast, assertive fashion attitude, asymmetry, horns or sharp accessories, and willingness to swing between delinquent casual, formal dress and festive variants without losing personality.

## Students / variants represented in this volume
- Yozakura Kirara
- Kyougoku Satsuki
- Motomiya Chiaki
- Rikuhachima Aru
- Onikata Kayoko
- Wanibuchi Akari

## Use rule
School DNA is a shared prior, not a uniform generator. When a student folder conflicts with the school average, the student's own reference wins.
