# Volume 4 — UI / Graphic Visual System

This artbook itself provides a useful graphic-design case: powder-blue section plates, bold uppercase sans-serif titles, thin rules, abundant white space and highly restrained accent color.

## Transferable rules
- one strong flat accent is enough when typography and spacing are disciplined
- section identity comes from layout rhythm, not decorative frames
- concept/profile pages use a white neutral field so silhouette, weapon and accessory colors are not contaminated by environment light
- logo/faction pages show that simple emblems can carry institutional identity across scenes
- in-world signage should obey the local district/school visual language rather than use a single universal UI style

Use these as hierarchy principles, not as a mandate to copy Blue Archive typography.
