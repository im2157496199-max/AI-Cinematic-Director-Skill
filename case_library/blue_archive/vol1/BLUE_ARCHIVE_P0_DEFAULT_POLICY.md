# BLUE ARCHIVE P0 DEFAULT POLICY

本项目用户已指定：Blue Archive 为默认人物/二次元商业视觉最高权重设定集之一。

## 当用户没有指定画风
默认优先：
1. Blue Archive Case Library
2. 用户当前题材/世界设定
3. 已纳入 Skill 的导演、摄影、美术、色光、空间、服装、故事、剪辑理论
4. 其他作品 Case Library

## BA二创
先检索目标角色卡和对应设定图索引，再设计：
character -> story_state -> outfit_state -> location -> action -> shot -> lighting -> prompt

## 原创人物
不复制具体BA角色。
迁移：轮廓清晰、头部识别、光环/世界身份符号、阵营一致性、日常+战术反差、商业可读性。

## 高权重质量检查
- 脸与发型是否仍是第一识别层
- 光环是否与角色/世界一致
- 服装是否有阵营/职业功能
- 武器/大附件是否与人体比例合理
- 多角色是否避免同脸
- 性感设计是否保留人物身份、骨盆/胸廓结构和服装受力
- 场景是否有日常生活信息，而非空白“二次元背景”
