# BLUE ARCHIVE — Visual DNA Core

## 角色设计

1. **头部识别优先**
   发色、发型、兽耳/角、光环、脸部表情共同形成第一识别层。即便换装或去掉枪械，头部仍应能认出人物。

2. **大轮廓 + 少数强锚点**
   不靠满身复杂纹样。长发、大翼、大枪、大外套、兽耳、盾、超长武器等一两个大形状先把 silhouette 做出来。

3. **统一制服框架 + 个性化模块**
   同学校/社团共享基础制服、徽标或主色，但通过头发、袜鞋、外套穿法、武器、包袋、发饰、姿态进行个性化。

4. **“可爱学生”与“真实/重型武器”的反差**
   枪械、炮、盾、机械设备常保持较明确的功能和材质；人物则轻、软、年轻。反差是世界辨识的重要来源。

5. **光环是世界观HUD式身份证**
   光环既是人物识别点，也是阵营/性格的几何设计空间。二创里除非明确改设定，不应随意换成普通圆环。

6. **服装先讲身份，再讲装饰**
   料理、警察、工程、医疗、图书、女仆、巫女、冬季军政等身份都通过功能服和附件直接表达。

7. **商业吸引力不等于统一露肤**
   不同角色通过可爱、成熟、冷酷、艳丽、恐怖、运动、性感等不同吸引路径建立市场辨识；不要把所有女性角色做成同一身材/同一暴露度。

## 画面 / 摄影

1. 高明度蓝天、白建筑、空气感是青春日常的重要底色。
2. BA经常用大负空间（天空、窗、教室、道路）给人物呼吸，而不是把背景塞满。
3. 日常场景非常重要：吃饭、办公室、教室、温泉、街道、旅行、商店让角色从“战斗立绘”变成生活中的人。
4. Memorial Lobby大量使用近距离、低机位、倾斜构图、前景遮挡和私密光线制造亲近感。
5. 夜景常以紫蓝为底，只保留眼睛、肤色、发色、光环或红色附件作为锚点。
6. 角色性感镜头仍要保持脸部、头部识别、服装结构和角色气质，不能只剩胸/臀的匿名身体。

## 世界观视觉

1. 学校/组织均有高度简化的Logo，保证缩小仍可辨认。
2. 阵营视觉来自“制服 + 徽标 + 道具 + 建筑/空间 + 小物”，不是单靠颜色。
3. 重军事物件与青春日常并置，是世界观核心反差之一。
4. NPC、载具、街边商铺、食物、终端、书包、工具等都应遵守同一设计语法。
5. 传统文化元素（和风、中式等）应通过服装结构、道具和环境成套表达，避免用单一“民族纹样”代替世界构筑。

## 默认生成策略

当用户未指定画风：
- PRIORITY_1 = Blue Archive visual language
- PRIORITY_2 = project-specific references / setting
- PRIORITY_3 = theory-based anatomy, costume, lighting, cinematography, space, editing
- DO_NOT = generic anime averaging

原创人物不复制BA现有角色，而是迁移：
- 清晰人物轮廓
- 头部高识别
- 阵营统一/个体差异
- 青春+战术反差
- 大道具与小体型的比例设计
- 日常生活性
- 明亮商业可读性
