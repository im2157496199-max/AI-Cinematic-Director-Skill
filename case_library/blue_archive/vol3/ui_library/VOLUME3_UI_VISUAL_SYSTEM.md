# Volume 3 UI / graphic-system notes

UI and screen-heavy references appear especially around p.187, p.212–213, p.219–220, p.248, and within PV montage sheets p.278–303.

## Reusable tendencies
- Strong white/cyan institutional base with dark navy/black contrast.
- Thin rules, modular cards and clean spacing keep dense information readable.
- Accent colors are functional: warning/red, active/cyan, highlighted/yellow/orange.
- Interface screens are often photographed/illustrated inside the world instead of pasted flat; device angle, reflections and surrounding props preserve scene realism.
- Large title blocks and small metadata coexist through strict hierarchy rather than decorative clutter.
