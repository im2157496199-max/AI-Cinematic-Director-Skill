# PV / cut visual storytelling — Volume 3

Reviewed p.186–303.

## Key lessons
- Sequence boards alternate wide establishing images, intimate close-ups, prop inserts and reaction shots. This prevents a montage from becoming a stack of pretty portraits.
- Color state changes are narrative signals: pale daylight for safety/daily life, deep blue for solitude/uncertainty, saturated red for threat/conflict, gold/pink for memory/hope.
- Props and screens often bridge cuts. Phones, tickets, signs, UI panels, food, equipment and doors create visual continuity.
- Environmental geometry matters: stairs, corridors, rooftops, train platforms and windows create direction and reveal.
- High-impact moments simplify the palette rather than adding more detail.
- Character grouping is relational: distance, orientation and who occupies foreground/background reveal status and emotional alignment.

## AI video transfer
Build shots in this order:
`story beat -> information target -> shot scale -> character action -> environment relation -> light/color state -> prompt`.
