## Lookup rules
- named student derivative work -> student folder first
- school/faction design -> `SCHOOL_VISUAL_DNA.md`
- scene/light request -> `environment_library/`
- CG/PV/storyboard request -> `illustration_library/`
- UI/graphic request -> `ui_library/`
- never infer a student identity from a multi-character page when the source is ambiguous
