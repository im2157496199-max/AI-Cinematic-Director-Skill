# Blue Archive Case Usage Validator

- [ ] If a named student is requested, the student folder was loaded before school averages.
- [ ] Face / hair / halo / signature motif remain stable unless redesign was requested.
- [ ] Scene images are taken from environment/illustration libraries, not from white profile-sheet backgrounds.
- [ ] School DNA is used as a prior, not a clone template.
- [ ] User-provided style/reference overrides the default Blue Archive case anchor.
- [ ] Multi-character extra pages are not assigned to a student without confidence.
- [ ] Lighting and composition still follow the neutral cinematography/art-direction rules.
