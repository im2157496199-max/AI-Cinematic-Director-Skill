# Manga / Sequential Still Validator

Use after NAME and before expensive final generation.

## Opening
- [ ] First 1–3 panels provide a reason to continue.
- [ ] Orientation is sufficient for comprehension, even if some information is deliberately withheld.
- [ ] Opening signals character / tone / world / dramatic promise rather than generic setup only.

## Character
- [ ] Important characters are distinguishable in behavior, voice, and visual identity.
- [ ] Character action is consistent with known motive, weakness, relationship, and role.
- [ ] Role-specific manners / vocabulary / behavior are researched when they materially affect the scene.
- [ ] Character exposition is not substituted for behavior.

## Story
- [ ] Sequence produces net dramatic movement.
- [ ] Conflict is not solved by unprepared coincidence.
- [ ] A competent character is not made inexplicably incompetent merely to manufacture trouble.
- [ ] Twist / reveal does not erase accumulated reader investment without meaningful payoff.

## Panel information
- [ ] Every P0/P1 panel has a clear job.
- [ ] Panels that can carry compatible multiple information layers do so.
- [ ] Redundant exposition panels are removed.
- [ ] Panel emphasis matches dramatic/emotional importance.

## Rhythm
- [ ] Panel size/density/framing create intentional pacing.
- [ ] Repetitive layout patterns are justified or varied.
- [ ] Important reactions receive enough visual time.
- [ ] Page-turn / reveal positions are intentional when page format is used.

## Spatial continuity
- [ ] Character positions and action axis remain readable across local action.
- [ ] Camera-side changes are motivated or reoriented.
- [ ] Gaze / prop / costume / environment continuity matches shared continuity state.

## Dialogue
- [ ] Dialogue sounds like the character rather than the author.
- [ ] Dialogue does not merely repeat visible information.
- [ ] Vocabulary / manners fit role and setting.
- [ ] Important subtext has visible behavioral support.

## NAME gate
- [ ] Rough layout has been tested before final rendering.
- [ ] What happens, what matters, what the reader notices, and what can be removed are all clear.
- [ ] Expensive generation is not being used to discover basic panel logic.

## Manga-to-video
- [ ] Panel and shot are not treated as identical units.
- [ ] Only high-value panels/transitions are promoted to shots.
- [ ] Added temporal motion preserves the original story result and emotional meaning.
