# story_character.md

> Lightweight checks for Story / Character tasks. Do not run every rule on simple single-image requests.

## STORY

- [ ] Premise is concrete enough to imply a character + action line.
- [ ] Need and desire are not accidentally the same field.
- [ ] Opponent attacks the actual desire / weakness rather than existing as generic “evil”.
- [ ] Plot events are connected by cause / decision / revelation, not only “and then”.
- [ ] Theme is mainly expressed through choices and consequences, not author speeches.
- [ ] Subplot, if present, affects or meaningfully contrasts the main line.
- [ ] Scene weave has no scene that changes nothing and reveals nothing.

## CHARACTER

- [ ] Major character has a desire or scene objective.
- [ ] Character is defined by behavior under obstruction, not only adjectives.
- [ ] Contradiction has a plausible root; it is not random trait stacking.
- [ ] Wound / secret / backstory is kept only if it changes present behavior.
- [ ] Two important characters do not share interchangeable reaction patterns and voices.
- [ ] Relationship-specific behavior is allowed; personality is not flattened into one mode.
- [ ] Dialogue has an action/intent behind it.

## AI GENERATION

- [ ] Psychological rules are translated to visible actions before prompt compilation.
- [ ] No default visual style is inherited from a character-writing source.
- [ ] Short-form work is allowed to compress story structure; do not generate filler shots just to satisfy a template.


## McKee value-turn checks

- [ ] Important scenes change at least one meaningful story value; activity alone is not treated as event.
- [ ] Opening and closing value states are not identical unless the scene has another indispensable dramatic function.
- [ ] Character action creates or widens a meaningful expectation-vs-result gap when escalation is needed.
- [ ] Progressive complications change pressure, stakes, knowledge, relationship, or problem type; they do not merely repeat.
- [ ] Crisis, when used, is a genuine dilemma rather than simply a large obstacle.
- [ ] Climax resolves the central dramatic question through a decisive action / irreversible value shift.
- [ ] Forces of antagonism are checked beyond the named villain.
- [ ] Exposition is carried inside dramatic action whenever possible.
- [ ] True character is inferred from consequential choices under pressure, not only self-description.
- [ ] Character contradictions are coherent and repeatable, not random trait stacking.
- [ ] Subtext is supported by desire / behavior; it is not decorative vagueness.
- [ ] Beat / scene / panel / shot are not treated as interchangeable units.
