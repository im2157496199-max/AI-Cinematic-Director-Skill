# Character Differentiation Validator

- [ ] Character identity uses multiple channels, not hair color alone.
- [ ] Base eye family is not being treated as a deterministic personality label.
- [ ] Emotion preserves the character's facial identity.
- [ ] Hair silhouette/texture supports identity without becoming a stereotype.
- [ ] Shared uniforms preserve faction continuity while allowing wear-attitude differences.
- [ ] Body type is chosen from role/context, not used as a personality verdict.
- [ ] Same-action characters still move/gesture differently.
- [ ] Props/accessories have role or behavior meaning.
- [ ] Color uses dominant/support/accent hierarchy rather than random equal saturation.
- [ ] Group members have readable contrast axes without forced maximum contrast everywhere.
- [ ] Relationship is visible through spacing/gaze/touch/orientation when relevant.
- [ ] Group pose is not just multiple unrelated solo poses.
- [ ] Anthropomorphism, if used, is based on motif decomposition rather than icon-sticking.
- [ ] Blue Archive/project case-library visual language outranks the book's period-specific moe styling.
