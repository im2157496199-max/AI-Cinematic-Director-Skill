# Art Direction / Production Design Validator

Use after production_design_spec and before final panel/shot generation.

## Story alignment
- [ ] The visible world expresses the same story, character logic, and theme as the narrative layer.
- [ ] Design is not generic décor.
- [ ] Style was not imposed merely because it is fashionable or “cinematic.”
- [ ] Design metaphor, if used, has a clear relationship to story/character.

## Character-space relation
- [ ] Important spaces reveal something specific about their inhabitants.
- [ ] Spaces feel accumulated / used / maintained rather than default showroom-perfect.
- [ ] Social/economic/status cues are supported by visible evidence rather than stereotype-only labeling.
- [ ] Environment can pressure, protect, seduce, isolate, or otherwise interact with character when relevant.

## Research/reference
- [ ] Factual references support period/culture/material/architecture when accuracy matters.
- [ ] References are transformed through project intent instead of copied blindly.
- [ ] Psychological/style references are separated from factual references.

## Color
- [ ] Palette has dramatic purpose.
- [ ] Color relationships are coordinated with intended lighting/camera treatment.
- [ ] No single color gimmick overwhelms story without deliberate reason.
- [ ] Color meanings are contextual, not hard-coded universal symbolism.

## Material/texture
- [ ] Major surfaces have material + finish + age + wear logic.
- [ ] Wear follows use, environment, maintenance, and material behavior.
- [ ] Contemporary spaces are not automatically pristine.
- [ ] Texture creates readable contrast and does not become noisy detail everywhere.

## Architecture/space
- [ ] Scale and spatial hierarchy support the scene.
- [ ] Circulation / entrances / exits / staging zones are coherent.
- [ ] Foreground / midground / background and sightlines support camera or panel composition.
- [ ] Large environments imply a coherent world beyond the frame when needed.
- [ ] Stylized / impossible architecture still follows internal visual logic.

## Props/décor
- [ ] Story-critical props are visually identifiable.
- [ ] Character-signature props are consistent across scenes.
- [ ] World-authenticating props support rather than clutter.
- [ ] Random clutter is not used as a substitute for specificity.

## Digital / AI execution
- [ ] AI capability is serving the design concept rather than driving arbitrary novelty.
- [ ] Generated spaces preserve depth, scale, material logic, and character-space relation.
- [ ] Virtual changes preserve continuity across shots/panels.
- [ ] Style remains user/reference driven, including optional JOJO-like or other stylized modes.


## Place / narrative agency
- [ ] Important scenes have a reason to occur in this specific place when location matters.
- [ ] If the environment is marked active/antagonistic, its spatial/material features actually constrain or change action.
- [ ] Repeated locations preserve learned geography unless a break is deliberate and story-relevant.

## Reality curation / stereotype check
- [ ] Real/reference locations have been curated; conflicting accidental signals are not copied blindly.
- [ ] Place/culture/period is not reduced to tourist icons, picturesque exoticism, or inherited stereotype unless the cliché itself is intentionally examined.
- [ ] The design identifies a story-relevant dominant characteristic rather than the easiest shorthand.

## Design visibility
- [ ] The project explicitly chooses `supportive_invisible`, `expressive_visible`, or `spectacle_forward` when this distinction matters.
- [ ] Spectacle is allowed when it is part of the intended experience; it is rejected only when it contradicts the narrative purpose.

## Visual progression / motif
- [ ] Key environments have been reviewed in story order, not only as isolated designs.
- [ ] Recurring motifs have defined appearances and evolving/consistent meaning.
- [ ] Central visual polarity is used only if the story actually contains a useful contrast.

## Temporal identity
- [ ] Period design is not evaluated only by surface replication; period/social spirit and story purpose are considered.
- [ ] Present-day design avoids accidental trend noise when longevity or neutrality is desired.
- [ ] Future design expresses the story/world logic rather than generic futurism.
- [ ] Contemporary production-era taste leaking into another period is intentional or consciously accepted.

## Negative space
- [ ] Empty areas, bare surfaces, darkness, missing objects, or reduced detail are allowed when they improve subjectivity, clarity, rhythm, or atmosphere.
- [ ] The image is not filled with detail merely because the generator can produce it.
