# Editing Validator

- [ ] Every retained shot adds emotion, story, rhythm, attention, or necessary continuity.
- [ ] The sequence is not cut merely because alternate angles exist.
- [ ] Rule of Six priorities are respected when tradeoffs occur.
- [ ] Emotion/story are not sacrificed solely to preserve perfect 3D continuity.
- [ ] Dialogue does not mechanically cut only on speaker changes.
- [ ] Reaction/subtext shots are used when they carry more meaning.
- [ ] Cut timing follows thought/emotional completion rather than fixed durations.
- [ ] Eye-trace across important cuts is checked.
- [ ] Required information arrives before confusion but not after the rhythm has died.
- [ ] Expensive/difficult generations are not protected by sunk-cost bias.
- [ ] Representative-frame contact sheet has been reviewed.
- [ ] Viewer complaints are checked for upstream causes.
- [ ] A/B versions have explicit hypotheses.
- [ ] Final edit exposes timing events for future music/sound design.
