# Character Color Design Validator

- [ ] Skin temperature/base is defined before hair and eye colors.
- [ ] Hair carries a readable dominant color mass or there is a deliberate alternative dominant element.
- [ ] Eye color functions as an accent or local focal support near the face.
- [ ] Outfit colors support the face focal hierarchy.
- [ ] Accent contrast is used intentionally, not everywhere.
- [ ] Shared-cast palettes preserve both belonging and differentiation.
- [ ] Mini/chibi versions reduce color complexity appropriately.
- [ ] Character local palette does not break the intended scene lighting logic.
